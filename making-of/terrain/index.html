The 2016 game's islands are made of triangles, and the triangles were baked: gigabytes of mesh files that only Unity can read, and that can't ship with a web game. So the port carries the recipe instead. A generator reads the same grayscale height maps and builds the same facets, and it gets checked against the baked files, chunk by chunk, until the two agree.

Reproducing a bug on purpose

A height map gives a height for each point on a grid spaced apart. To make a landscape, every vertex gets nudged by a small random amount, and then each square is cut into two triangles. The original does this and has one clever step: for each square it picks the diagonal that fits the map better, which should make the slopes read more naturally.

It doesn't work. When the code works out where to look in the map for the middle of the square, it uses the point's height where it means its depth. The test still returns a yes or a no, so every square gets a diagonal, nothing looked wrong, and the game shipped looking like itself. The pattern of those diagonals is part of the silhouette, so fixing the bug changes every square in the game. The generator keeps it behind a switch. Classic keeps 2016's diagonals. After flying both, I liked the fixed ones better, so the anniversary look uses those.

Try it: tick show flipped quads to see where the bug and the intended rule disagree. Untick 2016 diagonal bug and the outlines vanish, and the island changes everywhere at once. Slide jitter: the shipped Simonet value is . new island rolls a different one. 



      
Two ground surfaces

      

        The collision surface is the map on the grid, with no jitter. What you see is the jittered,
        triangulated mesh. The notes used to say the gap between the two was the jitter, which is
        small. Measuring it over thousands of placed objects said otherwise: most of the gap is the
        triangles themselves, a smooth reading of the map against a triangulation of it. On flat
        ground there's almost nothing between the two, so a spot check there passes. On a steep
        face it doesn't.
      

      

      

        Try it: click flattest to put the probe on the flattest dry ground on
        the section and read a tiny gap. Then click steepest, or slide the probe up a face yourself,
        and the gap and the slope rise together. Set jitter to zero and the gap is still
        there.
