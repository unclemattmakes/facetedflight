There's no design document for the 2016 game, and the code that shipped isn't the whole of what shipped. The rest is a pile of scenes and prefabs with numbers typed into them by hand, in a tool, years ago. So the port started like a dig, and every number gets labeled with the file and the object it was found in.

A number with a label

Every constant the port uses is generated from the 2016 project by a script, never typed. Each one carries the file it came from, the object inside that file, the line, and a trust level. Verified means it was read off something the game actually loaded. Derived means it's computed from verified ones by a stated formula. Code-default means only a script's initializer says so and nothing overrides it. Browse them all, and click a row for its note.

Try it: filter to derived and read the formula notes, then search resetDelay.

The script says one number, the scene says another

In Unity a script can give a variable a default, and the number that actually runs is whatever the scene wrote over it. The out-of-bounds countdown is the example. The script says one thing, and every one of the thirteen shipped missions says . So a number read from the script is only a guess, and the one that ran comes from the prefab the game actually loads, plus whatever that scene overrides. The port's notes record that going wrong more than once, and it's why every constant is generated by a script instead of typed.

The physics clock

The 2016 physics steps at , which is the exact float saved in the project, not the rounded figure most notes use. Every drag and thrust figure in the game only means something at that step. A headset draws at its own refresh rate, and none of the common ones divide that step evenly. So the port runs the physics on its own clock, and the renderer draws a blend of the last two states.

Try it: pick 60 Hz with interpolate unticked, and some frames move the ball further than others, though it never changes speed. Tick interpolate and the bars level out. The sim is only ever told the fixed step, never a frame time.
